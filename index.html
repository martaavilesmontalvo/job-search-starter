What should the search look for?

Keep essentials separate from preferences. Missing information should become a question, not an automatic rejection.

Put firm location, work-arrangement, travel and working-hour limits in Must meet below. Put flexible preferences in Would prefer. Anything still undecided belongs in What I am still deciding.

Include this if you request a recurring search.

Save your edits before creating instructions.

Where will you look?

Save a search-results URL, an employer's careers page, or a relevant specialist board. A source is a place to search, not an opening.

Run one title or work query at a time, inspect the responsibilities in a few results, then adjust. Save the working search link here. Set alerts on that site if it offers them.

Use the brief with an assistant

The buttons create text for you to review and copy. They do not start a search or create a scheduled task.

Save your brief and add at least one source first. Only search brief edits are saved when you create instructions. Save or cancel source and opening edits first.

Check the first output against the employer postings. If the assistant cannot browse, it should give you manual searches instead of claiming to have found jobs. A repeat request works only if the receiving tool supports and confirms scheduled browsing.

Keep a backup

Your entries stay in this browser when storage is available. They do not sync to other devices and can disappear if browser data is cleared or the file is opened differently.
